| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

MDVault is a local-first application designed with privacy and zero-telemetry principles. However, security vulnerabilities (such as arbitrary code execution through WebView, path traversal, or file injection) are taken seriously.

If you discover a security vulnerability:

1. **Do not create a public GitHub issue.**
2. Send a detailed report via GitHub Security Advisories or contact the repository maintainer directly.
3. Include:
   - Steps to reproduce the issue
   - Affected platform (Windows, macOS, Linux)
   - Potential impact
   - Suggested fix or workaround if available

Maintainers will review the report, issue a fix, and publish an updated binary within an appropriate disclosure window.
